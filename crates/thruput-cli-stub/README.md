# thruput-cli

This crate was renamed to [`thruput`](https://crates.io/crates/thruput). It
has no code; install the Thruput CLI with:

```sh
cargo install thruput --locked
```

The CLI's library is `thruput_cli` in the `thruput` package. The source lives
in [`crates/cli`](https://github.com/thruputchain/thruput-tools/tree/main/crates/cli).
